# たびノート — TABI NOTE

旅行の予定を組み立てて、写真とメモを添えて、**紙のしおりのような PDF / 画像に書き出せる**ウェブアプリです。
スマホのブラウザからそのまま使えて、ホーム画面に追加すればアプリのように全画面で開けます。

**日本語 / English / 한국어 / Français / 简体中文 / Español / Deutsch** に対応しています（ホーム右上から切り替え）。
見た目のテーマも **デフォルト / ダーク / モダン / ポップ / ナチュラル / 自動** から選べます。

## できること

- **旅をつくる** — タイトル・行き先・日程・テーマカラー・カバー写真を決めると、日数ぶんのページが自動で用意されます
- **時差** — 旅ごとに現地との時差を登録すると、予定の時刻の下に自宅の時間が併記されます（日をまたぐ場合は「前日 / 翌日」も表示）。飛行機など、予定ごとに別の時差を設定することもできます
- **多言語** — 画面もしおりの書き出しも 7 言語に対応。日付や曜日の表記は選んだ言語に合わせて切り替わります
- **見た目のテーマ** — アプリ全体の配色を 5 種類から選べます。「自動」は端末のライト / ダーク設定に追従します
  （書き出す PDF は印刷しても読めるよう、いつも紙の色のままです）
- **1 日ごとに予定を組む** — 時刻、種別（観光 / 食事 / 移動 / 宿泊 / 買い物 / 休憩 / その他）、場所、メモ、費用、リンク、写真を自由に追加
- **並べ替え** — ドラッグして順番を入れ替え。時刻順にワンタップで整列も
- **地図リンク** — 場所を入れておくと Google マップの検索リンクに。隣り合う予定どうしは「行き方を調べる」経路リンクになります
- **旅までにやること** — 予約や下調べなど、出発前に済ませることのチェックリスト。項目ごとに期限を設定でき、期限切れ・締切間近が色でわかります
- **持ち物リスト** — チェックボックスつき。達成率がバーで見えます
- **どちらのリストもテンプレートを自分で編集できます**（設定から）。項目の追加・名前の変更・並べ替え・初期状態にもどす、に対応。
  いま作っているリストをそのままテンプレートとして保存したり、テンプレートから不足分だけ読み込んだりもできます
- **旅日記** — 1 日ごとに日記を書けます。書いたそばから自動保存。その日に撮った写真もここから足せます
- **思い出アルバム** — 旅先で撮ったお気に入りの写真をひとことメモつきで残せます。何日目の思い出かを紐づけたり、その場でカバー写真にしたり、タップして全画面表示（スワイプで前後の写真へ）
- **通貨と為替** — 旅ごとに「現地で使う通貨」と「集計に使う自宅の通貨」、そのレートを登録できます。
  予定の費用は現地通貨のまま入れておけば、合計はいつも自宅の通貨で出ます（予定ごとに「自宅の通貨で払った」に切り替えることもできます）。
  レートを直せば、入力ずみの費用もまとめて計算し直されます
- **費用のまとめ** — 旅全体・1 日ごとの合計に加えて、**種別ごとの内訳**（観光 / 食事 / 移動 …）を割合つきのバーで表示。
  「明細をみる」で、全部の費用を日付順に一覧できます（種別でしぼり込み・タップでその予定を編集）
- **予算** — 旅の予算を決めておくと、使った額との差がバーで見えます。超えたら色が変わります
- **割り勘** — 予定ごとに「払った人」と「だれの分か」を決めておくと、
  ひとりずつの立て替え額・負担額と、**やりとりが最小になる精算のしかた**を出します
- **ファイルに書き出す**
  - 旅のしおり（PDF・A4 縦）… 表紙 ＋ 日ごとのページ（日記つき）＋ やること・持ち物・費用のまとめ（種別ごとの内訳・予算・割り勘の精算つき）＋ 思い出アルバム。長い日程や長い日記は自動でページ送りされます
  - この日の予定（PNG）… 1 日ぶんの縦長ポスター（日記つき）
  - 旅のまとめ（PNG）… 全日程を 1 枚に
  - 思い出アルバム（PNG）… 写真とひとことを 1 枚に
  - 表紙だけ（PNG）
- **バックアップ** — 写真・日記・テンプレートごと JSON に書き出し／読み込み。機種変更やブラウザ移行に

## データの扱い

すべてのデータは**その端末のブラウザ内（IndexedDB / localStorage）にだけ**保存されます。サーバーには何も送信されず、アカウントも不要です。
そのぶん、ブラウザのサイトデータを削除すると旅の記録も消えます。大事な旅は設定画面からバックアップを書き出しておいてください。

## 使っているもの

React 19 / TypeScript / Vite 7 / dnd-kit / jsPDF / html2canvas-pro / vite-plugin-pwa

多言語化は自前の軽量な仕組みで、辞書は `src/i18n/` にあります。日付・曜日・単複の判定は `Intl` に任せています。
通貨の記号・小数点以下の桁数・通貨名も `Intl` まかせなので、辞書を増やさずに表示言語についてきます。
費用の集計と割り勘の計算は `src/lib/expense.ts`、通貨の書式は `src/lib/money.ts` にまとまっています。

外部 API キーは一切不要です。地図は Google マップへのリンクとして開きます。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に出力
npm run preview
```

アイコン（`public/*.png`, `favicon.svg`）を作り直す場合:

```bash
node scripts/make-icons.mjs
```

## デプロイ

`main` ブランチへ push すると GitHub Actions が `dist` をビルドして GitHub Pages に公開します
（リポジトリの Settings → Pages → Source を **GitHub Actions** にしておいてください）。

`vite.config.ts` の `base` は `'./'` なので、プロジェクトページ（`/<repo>/`）でも独自ドメインでもそのまま動きます。
